
GAME NIGHT EXCHANGE
Design Handbook
The complete visual and interaction reference for the Game Night Exchange product family — Big Screen displays, Admin console, and Mobile companion. Built for a developer to implement without guesswork: every token, state, and animation used in the shipped screens is documented here with its literal value.

DESIGN PRINCIPLE
"Bloomberg terminal meets game-show graphics." Playful, saturated, over-the-top — never a banking app. Coins are treated like a live tradable asset: charts, tickers, odds, and payouts all borrow trading-floor visual language, rendered in bold flat color rather than financial-app blues and greys.

Screen family	Files
Big Screen (TV display, 1920×1080)	Dashboard, Round Started, Prediction Voting, Crowd Reveal, Betting Open, Prediction Result
Admin (desktop console)	Control Center, Rounds Management, Prediction Control, Player Ledger Detail
Mobile (player companion)	Wallet Home, Prediction Voting & Betting
01 — TYPOGRAPHY
Type families
Two families, strict roles. Never substitute one for the other's role — the contrast between the two IS the brand voice.

Role	Family	Weights used	Used for
Display / numeric / headings	Space Grotesk	500, 700	Coin totals, odds multipliers, round numbers, screen titles, countdown timers — anything that should feel like a ticking scoreboard.
Body / labels / UI chrome	Manrope	400, 600, 800	Body copy, eyebrow labels, buttons, badges, table text, nav.
Data / monospace (Admin tables)	JetBrains Mono	500, 600	Ledger amounts, IDs, timestamps in dense admin tables where digits must align.
Import: Space+Grotesk:wght@500;700&Manrope:wght@400;600;800 from Google Fonts, plus JetBrains Mono for admin density screens.

04 — SHAPE & RADIUS
Border radius
The signature shape move is asymmetric radius on cards — three corners round, one corner sharp (12px) — reading as a game-show plaque rather than a generic rounded rectangle. Reserve full symmetric rounding for pills, circles, and utility panels.

Token	Value	Usage
radius-sm	12–16px	Transaction cards, input fields, small tiles
radius-md	20–24px	Stat panels, header pills-with-corners, round-number card
radius-lg	28–36px	Big Screen chart panel, library section cards, control panel
radius-xl	44px	Player card (asymmetric: 44px 44px 44px 12px)
radius-full	999px / 50%	All buttons, status badges, avatar circles, sliders, toggles, timer ring
Asymmetric signature	e.g. 12px 44px 12px 44px	Prediction card (opposite-corner variant) — alternate the sharp corner between card types so the eye can tell card kinds apart at a glance

07 — STATUS & BADGES
State	Fill	Text	Indicator
Voting Open	#DFF24C	#14120F	pulsing dot, #14120F
Betting Open	#3D5AFE	#fff	pulsing dot, #fff
Locked	#14120F	#fff	none (static)
Settled	#2FAF5B	#fff	none
Round Active	#FF3FC0	#fff	none
Badge shape: full pill, 999px, padding 12px 24px, Manrope 800 13px uppercase, tracking .08em. Live/pulsing states pair the badge with an 9px dot animated via the pulse keyframe (opacity 1 → .4–.45, 1.4s ease-in-out infinite) — reserve the pulse for states that are actively counting down or accepting input; static states (Locked, Settled) get no dot.

08 — MOTION & ANIMATION
Keyframe	Definition	Timing	Used for
gne-pulse	opacity 1 → .4/.45 → 1	1.4s ease-in-out infinite	Live status dots, round-active header dot
gne-spin	rotate 0 → 360deg	6s linear infinite	Conic-gradient spiral decorative graphic
gne-draw	stroke-dashoffset → 0	1.6s ease-out, staggered .05–.5s per line	Chart line "drawing on" when the Dashboard mounts — each player's line draws in a fixed stagger order (Bas → Jorrit → Twan → Daan) so lines don't all snap in at once
gne-dot	SVG circle r: 6 → 9 → 6	1.2s ease-in-out infinite, staggered .2s apart per player after the draw-in completes (delays 1.7–2.3s)	Chart end-point markers "breathing" to read as live/updating
gne-ticker	translateX(0) → translateX(-50%)	linear infinite; duration is the tweakable variable	Bottom LED ticker marquee — content is duplicated once so the loop is seamless at -50%
Ticker speed values
Mood	Duration
Calm	32s
Live (default)	20s
Frenzy	9s
Micro-interactions elsewhere (buttons, cards): 150ms ease-in-out for hover/background transitions; toggle knob slides on a 150ms ease transition of its left position; hero-button press uses no duration on the shadow shrink — it should feel instant, not eased.

09 — BIG SCREEN PRESENTATION
Canvas
Fixed 1920×1080px canvas, not responsive — designed for a single TV/projector viewport. Background is paper #F4F1E4 with two oversized decorative blob shapes bleeding off-canvas (top-right circle #DFF24C, bottom-left rounded shape #9B2FF2) for visual texture without competing with data.

Dashboard anatomy
Zone	Height / position	Fill	Content
Header	top, ~48px padding, auto height	transparent (paper)	Round-name pill (dark, pulsing dot) left; Markets Open + Total Coins stat pills right
Market chart panel	flex:1 (fills remaining height), 32px side margins	#14120F	"MARKET — COIN VALUE BY ROUND" eyebrow + trend badge, SVG multi-line chart (4 players), round axis labels (R01…NOW), color-coded legend row
LED ticker	64px, full-bleed, pinned to bottom	#14120F	Infinite marquee of per-player coin deltas: name (player color) + signed coin change (green/red) + % swing (muted)
Chart construction
SVG viewBox 0 0 760 260, non-preserved aspect ratio (stretches to panel). Three faint horizontal gridlines at y=38/134/230 (#2a2820, 1px). Each player is a 4–5px rounded polyline plus a 7px circle marker pinned to the last data point (x=760) that pulses via gne-dot. Bas's line is 5px wide (vs 4px for others) as the slight visual lead indicator. X positions are fixed at 8 stops: 0, 109, 217, 326, 434, 543, 651, 760.

15 — CONTENT & VOICE
Player-facing copy (prediction questions, round names) is written in Dutch, in second/third person, short and specific — e.g. round names like "SPELLING BEE," prediction phrasing like "Kan Thomas binnen 30 seconden 10 hoofdsteden noemen?" UI chrome (labels, statuses, buttons) stays in English, uppercase, terse — "MARKETS OPEN," "VOTING OPEN," "CLOSE MARKET." Never mix the two within one string.

Numbers are always the hero: coin values, odds multipliers, and countdowns get the largest, boldest treatment on any screen. Round labels always follow the pattern ROUND ## — NAME.
