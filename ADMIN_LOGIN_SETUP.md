# Admin login setup

This build uses `ADMIN_PASSWORD_HASH` rather than a plaintext `ADMIN_PASSWORD`.

## 1. Create a password hash

From the project folder, run:

```bash
npm run admin:hash
```

The script asks for the new password twice without echoing it to the screen. For non-interactive use, you can still run `npm run admin:hash -- "YOUR NEW ADMIN PASSWORD"`.

The command prints one line beginning with:

```text
pbkdf2$sha256$600000$...
```

Copy that whole line. Do not add quotation marks around it in Netlify.

## 2. Configure Netlify environment variables

Set these variables for the site and make them available to Functions:

```text
ADMIN_USERNAME=your-admin-username
ADMIN_PASSWORD_HASH=paste-the-whole-generated-hash-here
SESSION_SECRET=at-least-32-random-characters
```

Do not create `ADMIN_PASSWORD`; this version does not use a plaintext admin password.

If your old `ADMIN_PASSWORD_HASH` begins with `$2a$`, `$2b$` or `$2y$`, it is bcrypt and must be replaced with a new hash generated by this project. This build intentionally uses Node's built-in PBKDF2 implementation so the Netlify function has no native or third-party password-hashing dependency.

## 3. Redeploy

After saving/changing Netlify environment variables, trigger a fresh production deploy. Then log in using the original plaintext password that you passed to `npm run admin:hash`.

`SESSION_SECRET` must be at least 32 characters. Changing it signs out existing sessions.
